CtACmdr {VERSION}
MOD ONLY zip

For people who ALREADY have UE4SS working
in Call to Arms: Panzer Elite.

No UE4SS yet? Use the other zip (the one that says Windows).

Your UE4SS must be a build that works on this game (UE 5.4).
The normal UE4SS v3.0.1 release does NOT: it loads no mods.
The mod's README says which build to use.


=====================================================
  THE ONE THING THAT GOES WRONG
=====================================================

  The  CtACmdr  folder must go INSIDE your UE4SS  Mods  folder.

  Not beside it. Not inside another folder.

  Your Mods folder is one of these:

        ...\call_to_arms_pe\Binaries\Win64\ue4ss\Mods     (newer UE4SS)
        ...\call_to_arms_pe\Binaries\Win64\Mods           (older UE4SS)


=====================================================
  INSTALL
=====================================================

  1. CLOSE THE GAME.

  2. Open your Mods folder (see above).
     You can see other mod folders in it, and a file called mods.txt.

  3. Double-click this zip to OPEN it, in a second window.
     Inside you see a folder called  CtACmdr.
     Drag that  CtACmdr  folder into the Mods folder.
     Do not drag the .zip file itself.

  4. Check it. This file must exist:

        Mods\CtACmdr\Scripts\main.lua

     RIGHT:   Mods\CtACmdr\Scripts\main.lua
     WRONG:   Mods\CtACmdr\CtACmdr\Scripts\main.lua   (one folder too deep)

  5. Start the game. Get in a tank. Press F3.

  The file enabled.txt inside the folder makes UE4SS load the mod.
  You do not need to edit mods.txt.


=====================================================
  KEYS
=====================================================

  F3 commander view on/off      F4 back to normal view
  ALT+NUM 8/2 forward/back      ALT+NUM 4/6 left/right
  ALT+NUM 9/3 up/down           ALT+NUM 5 reset
  ALT+NUM 0 save this tank      F6 write a report to CtACmdr.log


=====================================================
  REMOVE IT
=====================================================

  Delete the CtACmdr folder.
  To switch it off but keep it: delete CtACmdr\enabled.txt
  (setting it to 0 in mods.txt is NOT enough).

  Singleplayer only.
  More: https://github.com/murkzuk/CtACmdr
