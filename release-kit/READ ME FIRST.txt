CtACmdr {VERSION} - commander view for Call to Arms: Panzer Elite
=================================================================

This zip has everything in it. No other downloads, no scripts.

INSTALL (about 1 minute)
------------------------
1. CLOSE THE GAME.

2. In Steam: right-click the game > Manage > Browse local files.

3. Open:  call_to_arms_pe  >  Binaries  >  Win64
   This is the folder that holds  call_to_arms_pe-Win64-Shipping.exe

4. Extract this WHOLE zip into that Win64 folder.
   (Right-click the zip > Extract All, and type or paste the Win64 folder
   path. Or open the zip and drag everything across.)

   When you are done, next to the exe you should see:
       dwmapi.dll
       ue4ss         (a folder)
       READ ME FIRST.txt

5. Start the game.
   The first start sits on a BLACK SCREEN for up to a minute.
   That is normal for this game. Wait.

6. Get into a tank and press F3.


KEYS
----
  F3                Commander view on / off
  F4                Back to the normal view
  ALT + NUM 8 / 2   Camera forward / back
  ALT + NUM 4 / 6   Left / right
  ALT + NUM 9 / 3   Up / down
  ALT + NUM 5       Reset the camera offset
  ALT + NUM 0       Save this tank's position (remembered next time)
  F6                Write a report to CtACmdr.log (for bug reports)

Singleplayer only. Keep it out of multiplayer.


WHAT ELSE IS IN HERE
--------------------
UE4SS also comes with a few built-in helper mods (a cheat enabler and a
console enabler). They are switched OFF in this zip, so nothing changes
in the game except the commander view. To turn them on, edit
ue4ss\Mods\mods.txt and change the 0 after the mod's name to 1.


IF YOU ALREADY USE UE4SS
------------------------
Do not use this zip. It would replace your UE4SS files and settings.
Use the "mod-only" zip from the same download page instead.


IF ANTIVIRUS REMOVES A FILE
---------------------------
dwmapi.dll is how UE4SS loads into the game. It pretends to be a Windows
file, and some antivirus programs dislike that. If the mod does nothing:
  - Check your antivirus protection history for dwmapi.dll.
  - Allow it (or allow the Win64 folder), then extract the zip again.


IF NOTHING HAPPENS
------------------
  - The files must sit NEXT TO the exe, not in a sub-folder.
  - After one run, open  Win64\ue4ss\UE4SS.log
    Look for the line:   Starting Lua mod 'CtACmdr'
    If it is missing, send the log to the mod's author.
  - The game was still open while you copied. Close it and copy again.


REMOVE IT
---------
  Just the mod:   delete   Win64\ue4ss\Mods\CtACmdr
  Switch it off but keep it:   delete  ...\CtACmdr\enabled.txt
  Everything:     delete   Win64\dwmapi.dll   and   Win64\ue4ss

Nothing is written into the game's .pak files and your saves are never
touched. Steam "Verify integrity" ignores these files.

Your saved camera positions live in  Win64\CtACmdr_views.txt
